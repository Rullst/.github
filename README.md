## 📌 About This Repository

This is the special **`.github`** repository for the **[Rullst](https://github.com/Rullst)** organization on GitHub.

In GitHub's architecture, a public repository named `.github` within an organization serves as the central hub for:
1. **Organization Profile (`profile/README.md`)**: The presentation page rendered at the root of the organization ([github.com/Rullst](https://github.com/Rullst)).
2. **Default Community Health Files**: Fallback configurations, sponsorship definitions, issue templates, and guidelines automatically inherited by all repositories under the `@Rullst` umbrella that do not define their own.
3. **Organization-wide Sponsorship (`.github/FUNDING.yml`)**: Controls the "Sponsor" button across Rullst projects.

---

## 📂 Repository Structure

```text
.github/
├── .github/
│   └── FUNDING.yml       # Global GitHub Sponsors and platform funding configuration
├── profile/
│   └── README.md         # Public organization profile rendered at https://github.com/Rullst
├── FUNDING.yml           # Root-level funding declaration
├── LICENSE               # MIT License
└── README.md             # This file (overview of the .github meta-repository)
```
